# Летопись глазами губернаторов — интерактивный отчёт

Лендинг-отчёт о реализации мультимедийного проекта: пять исторических личностей, четыре фильма.
Стек: React 18 + TypeScript + Vite 6 + Tailwind CSS 4 + GSAP 3.13 (ScrollTrigger, Draggable, SplitText, CustomEase) + Lucide.

## Запуск

```bash
cd site
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
```

Сборка использует `base: './'`, поэтому `dist/` можно выложить на любой статический хостинг или в подпапку.

### Медиафайлы

Производные медиа лежат в `public/media/` и создаются скриптом из исходной папки `../Летопись-20261116T083913Z-1-001/Летопись`:

```bash
npm run media                  # дособрать недостающие файлы
FORCE=1 npm run media          # пересобрать всё
node scripts/build-media.mjs "D:/путь/к/Летопись"   # другой путь к исходникам
```

Нужен `ffmpeg`/`ffprobe` в PATH. Исходники не изменяются.

- `public/media/films/<id>.mp4` — итоговые ролики «ролик N.mp4» **без перекодирования**, только перепаковка с `+faststart` (видео начинает играть до полной загрузки).
- `public/media/img/<id>/*-960.webp`, `*-480.webp` — все 63 изображения из папок «Картинки».
- `src/data/media-manifest.json` — карта «производный файл → исходник», длительности и размеры видео.

Готовые медиафайлы хранятся в репозитории (≈ 82 МБ), чтобы сайт собирался на GitHub Pages без исходной папки.

## Публикация

При каждом push в `main` workflow `.github/workflows/pages.yml` собирает сайт и публикует его на GitHub Pages.

## Где что менять

| Файл | Содержимое |
|---|---|
| `src/data/project.ts` | Тексты разделов, показатели 04 / 04 / 25, пять личностей |
| `src/data/films.ts` | Четыре фильма: название, герои, подзаголовок, описание, видео, постер, соотношение сторон, длительность, ссылки на публикации, кадры |
| `src/data/distribution.ts` | Площадки и их статус |
| `src/data/stats.ts` | Статистика (все значения `null`, пока нет данных) |

### Добавить ссылки на опубликованные ролики

В `src/data/films.ts` у нужного фильма заполните `publications`:

```ts
publications: { vk: 'https://vk.com/video…', telegram: 'https://t.me/…', max: null, ok: null },
```

Ссылки появятся в разделе «Распространение» у соответствующей площадки, а счётчик ссылок обновится в «Результатах».

### Изменить статус площадки

`src/data/distribution.ts`: `status: 'pending' | 'planned' | 'published'` и при желании `url` — ссылка на канал/сообщество.

### Добавить статистику

`src/data/stats.ts` — данные по каждому ролику (`null` — нет данных):

```ts
byFilm: {
  ivan: { views: 81_205, engagement: 455, reach: 40_000 },
  …
},
updatedAt: '2026-11-18',              // подпись «Данные на …»
byPlatform: { vk: { views: 80000, placements: 4 }, … },
extra: [{ label: 'новых подписчиков', value: 1200 }],
```

`views` — просмотры, `engagement` — реакции + комментарии + репосты, `reach` — виральный охват (выводится со знаком «≈»).
Итоги считаются автоматически как сумма по роликам; ручной итог можно задать в `totals`.
Блок «Результаты» показывает только заполненные значения.

### Раздавать видео с внешнего хостинга

В `films.ts` замените `video: { src: localVideo('ivan').src }` на `video: { src: 'https://cdn.example.com/ivan.mp4' }`. Длительность `duration` можно оставить числом или поставить `null` — плеер возьмёт её из метаданных.

## Компоненты

- `HeroSection` — заголовок с посимвольным раскрытием (SplitText), коллаж кадров из четырёх фильмов, влетающий с разных сторон; при прокрутке коллаж перестраивается к колоде.
- `ProjectContext` — «История, рассказанная по-новому»: показатели 04 ролика · 04 площадки · 25 единиц контента барабанами (одометр, число читается и без JS), список пяти личностей с номерами фильмов.
- `FilmDeck` — центральная колода из четырёх карточек: состояния Active / Next / Background / Previous, флаги Transitioning / Playing. Одна функция `goTo` управляет хореографией: подъём → уход в сторону с поворотом → выход следующей карточки из глубины → перестройка остальных → смена текста через маски → смена фона под акцент фильма. Быстрые нажатия прерывают текущий таймлайн и доводят карточки до целевых поз без «зависаний».
  Управление: стрелки, клавиши ← →, Enter, перетаскивание мышью, свайпы (вертикальная прокрутка остаётся нативной), клик по боковой карточке, индикатор с именами. Колесо мыши не перехватывается.
- `FilmCard` — карточка с тремя слоями трансформаций (поза в колоде / сборка при входе / разлёт при выходе).
- `DeckController` — стрелки и индикатор `01 / 04`.
- `CinematicVideoPlayer` — FLIP-разворот активной карточки в плеер и обратное сворачивание; play/pause, перемотка, громкость, полноэкранный режим, Esc, пробел, ← →, ловушка фокуса и возврат фокуса на кнопку, состояния загрузки/ошибки, запасная кнопка при запрете автозапуска.
- `ProductionGallery` — факты из материалов (4 ролика, 3:47 хронометража, 63 иллюстрации, 60 анимированных сцен), разворот кадров с маскированным раскрытием, строка художественных качеств и две ленты кадров, движущиеся навстречу при прокрутке.
- `DistributionSection` — четыре площадки с нейтральными статусами и местом под ссылки.
- `ResultsSection` — показатели из `stats.ts` или нейтральное состояние.
- `FinalSection` — «История продолжается.», веер из четырёх обложек (клик открывает фильм в колоде), футер.
- `Navigation` — шапка, индикатор текущего раздела, мобильное меню.

`prefers-reduced-motion`: прокруточные и декоративные анимации отключаются, переходы колоды — короткие кроссфейды.
